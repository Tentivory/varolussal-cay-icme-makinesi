# 🍵 Varoluşsal Çay İçme Makinesi

## Bu Ne?

Bu proje, insanlığın en temel ihtiyacı olan çay içme eylemini, varoluş felsefesiyle harmanlayan **devrim niteliğinde** bir yazılımdır.

Her yudum, sadece bir sıvı değildir. Her yudum, evrenin anlamsızlığına karşı atılmış bir adımdır. Ya da değildir. Bilmiyoruz.

## Özellikler

- **Gerçek Çalışan Kod**: Evet, gerçekten çalışır. Python 3 ile.
- **Varoluşsal Şikayet Üretimi**: Her çalıştırmada farklı hayat sorgulamaları.
- **Zaman Gecikmesi**: Gerçek çay içme hızını simüle eder (yaklaşık).
- **Sıfır Bağımlılık**: Sadece standart kütüphane. Demlik gibi saf.

## Kurulum ve Kullanım

```bash
git clone https://github.com/Tentivory/varolussal-cay-icme-makinesi.git
cd varolussal-cay-icme-makinesi
python3 cay_ic.py
```

**Uyarı**: Bu yazılımı çalıştırdıktan sonra hayata bakış açınız değişebilir. Sorumluluk kabul etmiyoruz.

## Neden Bu Proje?

Çünkü bazen bir çay içmek bile, dünyanın tüm sorunlarını çözmüyor. Ama denemek önemli.
